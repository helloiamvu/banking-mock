# banking-mock

UI-only mock of a banking app, rebuilt 1:1 from a reference screencast. No backend; all data is hardcoded.

Stack: Vite + React + TypeScript + framer-motion.

## Run

    npm install
    npm run dev

- Desktop: open http://localhost:5173 to see the app in a phone frame.
- Phone (same Wi-Fi): open the `Network:` URL Vite prints, e.g. http://192.168.x.x:5173.
- Full-screen, native feel: in Safari tap Share, then **Add to Home Screen**, and launch it from the icon. The browser bars go away.
